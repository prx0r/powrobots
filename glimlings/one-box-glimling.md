# The One-Box Glimling

## The Customer Experience

1. **Design with Muse** — "Turn my cat into a little woodland creature that looks after my mum's plants." Muse helps develop the appearance, POW Studio produces a preview using a validated character template.

2. **Personalise the gift** — Choose colour, name, expression. Add a plant sensor, another character or a gift message.

3. **Approve and buy** — POW provides final price and delivery estimate. Customer reviews and pays through Shopify.

4. **One parcel arrives** — Elecrow prints the character, includes preprogrammed voice module and approved plant sensor, checks the kit and packs everything.

5. **Adopt the Glimling** — Recipient plugs it in, scans QR code, photographs and names their plant, connects the sensor, chooses personality.

**The recipient should not have to compile firmware, solder wires, create an MCP server or buy another component.**

## Keep Manufacturing Inexpensive

### One Fixed Electronic Configuration

- Same internal mount
- Same LED position
- Same microphone and speaker access
- Same assembly procedure regardless of appearance

### Three Customisable Base Shapes (Initial)

1. Mushroom
2. Cat-inspired woodland spirit
3. Frog

### Electronics Installed by Elecrow

Not snap-in by customer. Reserve modular self-assembly for enthusiasts.

### First Kit Contents

- One complete Glimling
- One fully supported plant sensor
- Additional sensors in expansion catalogue

### Gift Code Option

- Purchase standard electronic Glimling
- Include gift code for recipient to design own character later
- Avoids guessing someone else's aesthetic
