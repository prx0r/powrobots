# Glimlings Garden — The Full Collection

## The Vision

The eight characters should feel like inhabitants of the same enchanted garden, but each should react differently to its plant. The strongest product concept is that the creature itself expresses what the plant needs: a fern curls, a mushroom changes its glow, a flower closes, and a frog looks increasingly concerned.

Design the collection around three shared hardware platforms: **Glow**, **Motion** and **Environment**. Characters can combine them, but their electronics, mounting interfaces and sensor connectors should be standardised. That gives the design MCP a small number of real manufacturing constraints rather than eight unrelated sets of rules.

---

## The Three Hardware Platforms

| Platform | Components | Use For |
|----------|------------|---------|
| **Glow** | ESP32 + LED + diffuser | Illuminated characters |
| **Motion** | ESP32 + servo + mechanism | Moving characters |
| **Environment** | ESP32 + temp/humidity/light/baro | Weather stations |

## The Physical Design Rule

**Separate the plant sensor from the character.**

A replaceable probe goes into the soil; the decorative character sits beside or clips onto the pot. This keeps wet soil away from the electronics and allows the same character to work with different planters.

```
PLANT SENSOR (in soil)
    ↓
CABLE (waterproof)
    ↓
CHARACTER (beside pot)
    ↓
USB-C (power)
```

### Visual System
- Natural silhouettes
- Muted earthy colours

- Colour
- Expression

**Without altering standard internal hardware.**

## Start Indoor, Validate Outdoor Later

- **Indoor range first** — no weatherproofing needed
- **Outdoor variants later** — separate validation
- **Rechargeable batteries** — separate product line
- **Water pumps** — separate product line

**Don't promise outdoor features on indoor products.**
