# Glimlings: Final Vision

## The Product

**"Turn the things you love into little useful guardians."**

Not: "Here is a plant gadget"
But: **"Turn something you love into a useful little living system."**

---

## What People Upload

- Their pet
- Their plant
- Their room aesthetic
- A sketch
- A moodboard
- A child's drawing
- A photo of a mushroom / frog / gnome / ghost they like

## What Glimlings Studio Creates

1. **A character design**
2. **A manufacturable shell**
3. **A useful role in the network**

**The product is not just "custom 3D model." It is: custom identity + real function.**

## Three Levels of Customisation

### Level 1 — Inspired By

User uploads pet photo or image.

Studio extracts:
- Colours
- Vibe
- Facial expression
- Silhouette cues
- Texture cues

Maps onto **known character archetype**.

Example: "Turn my orange cat into a mushroom Glimling"
→ Orange cap, sleepy eyes, cat-ear silhouette, warm cream body

**Easiest and safest.**

### Level 2 — Stylised Likeness

User uploads:
- Pet photo
- Multiple angles
- Favourite expression

Studio generates recognisable stylised character:
- Cat-like ghost
- Dog-like frog
- Owl-like plant spirit

Still built on known shell family and standard internal geometry.

**Probably the sweet spot.**

### Level 3 — Full Custom Creature

User uploads images/prompt/sketch, gets original shell.

More validation, more print risk, more failures, more support.

**Do this later.**

---

## The Key Insight

**The inside stays standard. The outside becomes personal.**

Every Glimling uses:
- Same core mount
- Same button access
- Same speaker opening
- Same mic opening
- Same USB path
- Same LED/light path

Only the outer identity changes.

So:
- Electronics remain cheap
- Software stack remains unified
- Compatibility graph remains clean
- Customisation remains high-value
