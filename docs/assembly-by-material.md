# Assembly by Material

## The Process (Same for All Materials)

### Step 1: Inspect Shell
- Check for print defects
- Verify snap-fit rails
- Check LED window is clear
- Verify speaker holes are open
- Check USB-C opening aligns

### Step 2: Insert Atom Voice
- Push Atom Voice into shell cavity
- Ensure it clicks into place
- Verify USB-C aligns with opening
- Verify speaker aligns with holes
- Verify LED aligns with window
- Verify button is accessible

### Step 3: Test
- Plug in USB-C
- Verify LED lights up
- Test button press
- Test speaker sound
- Test microphone pickup
- Test Grove port (if using sensors)

### Step 4: Snap Lid
- Align lid with base
- Press until click
- Verify no gaps
- Verify button still accessible

**Total time: 30 seconds. Tools: None. Skills: Can hold object.**

## Recommendation

### Start With: MJF Nylon
- Cheapest (£2.00)
- Toughest (snap-fit friendly)
- Most forgiving for prototyping
- Dyeable to any colour

### Upgrade To: SLA Resin
- Smoother finish
- Better detail
- Translucent option for LED glow
- Good for premium product

### Premium: SLA Coloured or Metallic
- Full colour or metallic finish
- Highest perceived value
- For deluxe/luxury tier

### The Play

1. **Prototype** with MJF Nylon (cheapest, toughest)
2. **Test** fit and function
3. **Upgrade** to SLA for production
4. **Offer** material tiers at different prices
