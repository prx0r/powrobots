## The Three Options

### Option 1: Use M5Stack StackChan ($100)

- Already has ESP32-S3, mic, speaker, LED
- Add custom POW shell
- Fastest path to prototype
- **Best for Christmas 2026**

### Option 2: Use M5Stack Atom Voice ($13.50)

- Cheaper, simpler
- Add custom POW shell
- Good for budget product
- **Best for testing concept**

### Option 3: Custom PCB (Cheapest at volume)

- Design our own board
- Use ESP32-S3 module
- Add mic, speaker, LED, button
- Cheapest per unit at 1000+
- **Best for production**
