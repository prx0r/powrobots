# Swappable Parts System — How It Works

## The Concept

**One base unit (electronics) + Many heads (characters) = Collect them all**

```
BASE UNIT (£34.99):
  ESP32-S3 + soil sensor + LED + USB-C
  Snap-fit interface on top
  1 head included

EXPANSION HEADS (£10.99-19.99):
  Character shell (mushroom, frog, ghost, etc.)
  Snaps onto base unit
  Different colours, shapes, expressions
  Optional: NFC, motion sensor, extra LEDs
```

## The Mechanical Interface

### Base Unit (Top View)

```
┌─────────────────────┐
│  ┌───┐       ┌───┐  │
│  │   │       │   │  │  ← Snap clips (4x)
│  └───┘       └───┘  │
│                     │
│    ○ LED (RGB)      │  ← Light pipe opening
│                     │
│  ┌─┐             ┌─┐│
│  │ │             │ ││  ← Alignment pins (2x)
│  └─┘             └─┘│
│                     │
│  ┌─────────────┐    │
│  │ Soil sensor │    │  ← Sensor connector
│  │ connector   │    │
│  └─────────────┘    │
│                     │
│  ┌───┐       ┌───┐  │
│  │   │       │   │  │  ← Snap clips (4x)
│  └───┘       └───┘  │
└─────────────────────┘
```

### Head (Bottom View)

```
┌─────────────────────┐
│  ┌───┐       ┌───┐  │
│  │ ▼ │       │ ▼ │  │  ← Snap clip receivers
│  └───┘       └───┘  │
│                     │
│    ○ Light pipe     │  ← Receives LED light
│                     │
│  ┌─┐             ┌─┐│
│  │○│             │○││  ← Alignment pin holes
│  └─┘             └─┘│
│                     │
│  (character shell)  │  ← Mushroom cap, frog face, etc.
│                     │
└─────────────────────┘
```

### Interface Features

| Feature | Purpose |
|---------|---------|
| 4 snap clips | Secure attachment, easy removal |
| 2 alignment pins | Prevent wrong orientation |
| Light pipe | Transfers LED light from base to head |
| Sensor opening | Soil probe connects through |

- Base unit: £34.99
- First head: Included
- Total: £34.99
- Affordable impulse buy

### 2. Collectibility

- Heads: £10.99-19.99 each
- Cheap to collect
- 8 characters to collect
- Seasonal limited editions

### 3. Giftability

- Expansion heads as gifts
- No new electronics needed
- Just snap on new character
- Perfect for birthdays

### 4. Personalisation

- Choose head for mood
- Swap heads daily
- Software moods change too
- Same base, different personality

### 5. Upgradeable

- Start with basic head
- Add NFC head later
- Add motion head later
- Add camera head later

### 6. Viral Potential

- Share collections
- Trade heads
- Limited editions
- Social media content
