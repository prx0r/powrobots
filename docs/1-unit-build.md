# 1-Unit Build: Yes or No

## Answer: YES

You can design using any engine and get 1 full product delivered. Here's exactly how and what it costs.

---

## The Pipeline (1 Unit)

```
1. Order components    → Alibaba (MOQ 1, 2-5 days)
2. Order enclosure     → JLC3DP (MOQ 1, 2-4 days)
3. Assemble            → Manual (yourself) or Prism Electronics
4. Flash firmware      → USB cable
5. Package             → Branded box + instructions
6. Ship                → Royal Mail £3.50
```

**Total time: 7-14 days from order to delivery**

## The Hard Truth

**Yes, you can build 1 unit.** But:

1. **Shipping kills you** - £8 inbound shipping for £15 of parts
2. **Manual assembly** - 30-60 min per unit (your time)
3. **No test fixture** - Manual testing per unit
4. **No economies of scale** - Each unit costs the same

**At 10 units**, shipping drops to £3-4 per unit and you can use UK Electronics for assembly.

**At 50+ units**, Seeed Fusion ODM becomes viable at £15-20 per unit.

---

## Recommendation

1. **Build 1 prototype** of each engine (manual assembly, £26-35 each)
2. **Test thoroughly** - validate all sensors, functions, enclosure fit
3. **Document assembly process** - time each step
4. **Order 10 of best seller** - use UK Electronics for assembly
5. **Scale with Seeed** - when demand is proven

**Total investment for 7 prototypes: £216** (all-in, delivered)
